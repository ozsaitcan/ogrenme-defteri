# Yazılım Terimleri Sözlüğüm

Bu dosyada öğrendiğim teknik terimleri,
Türkçe anlamlarını ve örneklerini tutacağım.

| İngilizce Terim | Türkçe Anlamı | Açıklama |
|---|---|---|
| Repository | Depo | Proje dosyalarının saklandığı yer |
| Commit | Kaydetme | Yapılan değişikliklerin Git'e kaydedilmesi |
| Branch | Dal | Projenin ayrı çalışma alanı |
| Pull Request | Değişiklik isteği | Kod değişikliklerini birleştirme isteği |
| Terminal | Komut satırı | Bilgisayara komut verdiğimiz ortam |
