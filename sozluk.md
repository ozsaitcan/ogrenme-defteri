# Hafta 01 – Zorunlu Terimler

## 1. Temel kavramlar

| Terim | Türkçe | Kendi cümlemle | Örnek |
|---|---|---|---|
| HTML | İşaretleme dili | Web sayfasının iskeletini oluşturur. | Başlık ve paragraf oluşturmak. |
| CSS | Stil dili | Web sayfasının görünüşünü düzenler. | Butona web sitesine renk katmak. |
| JavaScript | Programlama dili | web sayfasına hareket ve etkileşim kazandırır. | Butona basınca çalışmasını sağlamak. |
| Dynamic | Dinamik | İçeriğin kullanıcıya veya duruma göre değişmesidir. | Kullanıcıya özel karşılama mesajı. |

## 2. Planlama ve tasarım

| Terim | Türkçe | Kendi cümlemle | Örnek |
|---|---|---|---|
| Requirements Document | Gereksinim belgesi | Bir projenin nasıl olması gerektiğini ve neler içermesi gerektiğini anlatan belgedir. | Bir müşterinin web sitesinde ürünler iletişim ve hakkımızda sayfaları istemesi. |
| Information Architecture | Bilgi mimarisi | Bir web sitesindeki bilgilerin ve sayfaların düzenli şekilde organize edilmesi. | Ana sayfa ürünler ve iletişim sayfalarının menüde düzenli sıralanması. |
| Sitemap | Site haritası | Bir web sitesinde bulunan sayfaların tamamını gösteren haritadır. | Bir sitenin ana sayfa hakkımızda hizmetler ve iletişim sayfalarını gösteren liste. |

## 3. Teknoloji ve kodlama

| Terim | Türkçe | Kendi cümlemle | Örnek |
|---|---|---|---|
| API | Uygulama programlama arayüzü | İki farklı yazılımın birbiriyle iletişim kurmasını sağlayan sistemdir. | Bir hava durumu uygulamasının hava durumu bilgilerini başka bir servisten alması. |
| API Key | API anahtarı | Bir API'ye erişmek için kullanılan özel anahtardır. | Bir hava durumu servisine bağlanırken API Key kullanmak. |
| Environment Variable | Ortam değişkeni | Programın çalışması için gereken bazı bilgileri saklayan ortam değişkenidir. | Veritabanı şifresini ortam değişkeninde saklamak. |
| Git | Sürüm kontrol sistemi | Kodlarda yapılan değişiklikleri takip etmeye yarayan sürüm kontrol sistemidir. | Bir projede yaptığım eski değişikliklere geri dönebilmek. |
| Repository | Depo | Bir yazılım projesinin dosyalarının ve kodlarının saklandığı depodur. | GitHub üzerinde bir web sitesi projesi oluşturmak. |
| Framework | Yazılım çatısı | Yazılım geliştirirken işleri kolaylaştıran hazır bir çalışma yapısıdır. | React kullanarak web uygulaması geliştirmek. |
| Library | Kütüphane | Belirli işlemleri kolayca yapmamızı sağlayan hazır kod koleksiyonudur. | Bir JavaScript kütüphanesi kullanarak tarih işlemleri yapmak. |
| Dependency | Bağımlılık | Bir programın çalışması için ihtiyaç duyduğu başka bir yazılım veya pakettir. | Bir projede React paketine ihtiyaç duymak. |
| Low-code | Az kodla geliştirme | Çok az kod yazarak uygulama geliştirme yöntemidir. | Sürükle-bırak araçlarıyla basit bir web sitesi hazırlamak. |

## 4. Test ve kalite

| Terim | Türkçe | Kendi cümlemle | Örnek |
|---|---|---|---|
| Unit Test | Birim testi | Kodun küçük bir bölümünün doğru çalışıp çalışmadığını kontrol eden testtir. | Hesap makinesindeki toplamamişlemini ayrı olarak test etmek gibi. |
| Integration Test | Entegrasyon testi | Birden fazla kod bölümünün birlikte doğru çalışıp çalışmadığını konttrol eden testtir. | Giriş ekranının kullanıcı bilgilerini veritabanıyla doğru şekilde kontrol etmesi. |
| End-to-End Test | Uçtan uca test | Bir uygulamanın baştan sona kullanıcı gibi test edilmesidir. | Siteye girip üye olmak, ürün seçmek ve spariş vermeyi denemek. |
| Test Pyramid | Test piramidi | Yazılım testlerinin hangi seviyelerde ve ne kadar yapılması gerektiğini gösteren modeldir. | Bir projede çok sayıda birim testi daha az entegrasyon testi yapmak. |
| CI/CD | Sürekli entegrasyon ve teslimat | Kod değişikliklerinin otomatik test edilmesini ve yayınlanmasını sağlayan sistemdir. | Kodumu GitHub'a gönderdiğimde testlerin otomatik çalışması. |
| Pipeline | İşlem hattı | Yazılımın test, kontrol ve yayınlama aşamalarından geçtiği işlem sırasıdır. | Kodun önce test edilmesi ardından hatasızsa yayınlanması. |

## 5. Yayın ve altyapı

| Terim | Türkçe | Kendi cümlemle | Örnek |
|---|---|---|---|
| Hosting | Barındırma hizmeti | Bir web sitesinin internette yayınlanmasını sağlayan barındırma hizmetidir. | Hazırladığım web sitesini bir hosting hizmetine yükleyerek internette yayınlamak. |
| Domain | Alan adı | Bir web sitesine ulaşmak için kullanılan internet adresidir. | Google.com veya YouTube.com birer domain örneğidir. |

## 6. Yapay zekâ

| Terim | Türkçe | Kendi cümlemle | Örnek |
|---|---|---|---|
| Hallucination | Halüsinasyon | Yapay zekanın yanlış veya gerçekte olmayan bilgileri doğruymuş gibi sunmasıdır. | Yapay zekanın olmayan bir yazılım kütüphanesini varmış gibi anlatması. |
| Fake Package | Uydurma paket | Gerçekte bulunmayan veya güvenilir olmayan bir yazılım paketidir. | Olmayan bir paketi projeye yüklemeye çalışmak. |
| Context Window | Bağlam penceresi | Yapay zekanın bir konuşmada veya işlemde dikkate alabildiği bilgi miktarıdır. | Uzun bir kod dosyasını incelerken yapay zekanın belirli bir bilgi sınırına sahip olması. |

## 1. Genel ve çalışma düzeni

| İngilizce         | Okunuş      | Türkçe anlamı                                              |
| ----------------- | ----------- | ---------------------------------------------------------- |
| repository (repo) | ripozitori  | Proje klasörü +tüm geçmişi; Git'in sakladığı şey           |
| commit            | kımit       | kaydedilmiş bir değişiklik paketi, açıklama mesajıyla      |
| branch            | branç       | Dal: ana koddan ayrılıp üzerinde güvenle çalıştığın kopya  |
| main              | meyn        | Ana dal: herkesin kullandığı "doğru sürüm"                 |
| pull request (PR) | pul rikuest | "Değişikliğimi ana dala al" isteği; inceleme burada olur   |
| merge             | mörc        | Birleştirmek: bir dalı diğerine katmak                     |
| squash            | skuoş       | Birden çok commit'i tek commit'e sıkıştırarak birleştirmek |
| rebase            | ribeyz      | Dalını, ana dalın en son haline "yeniden oturtmak"         |
| conflict          | konflikt    | Çakışma: iki kişi aynı satırı değiştirmiş                  |
| push / pull       | puş / pul   | Değişikliği GitHub'a göndermek / GitHub'dan almak          |
